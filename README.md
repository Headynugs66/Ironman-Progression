# Ironman Progression Chart

An interactive Old School RuneScape progression guide for Ironman and Hardcore Ironman accounts. It has one gear chart for all combat styles, a boss chart with hardcore risk ratings, an early-game route, and a chart for each of the 24 skills.

- Hover any box (or tap it on a phone) for levels, quests, costs, locations and drop rates.
- Click to mark a box done. Right-click or Shift+click skips it.
- Under "My stats and backup", import a character from the hiscores or WikiSync to tick off what is already done.
- Progress saves in your own browser. Use the backup code to move it between devices.

Drop rates and costs come from the OSRS Wiki. Rates marked with ≈ are approximate.
